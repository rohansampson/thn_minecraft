TEXTURE FILES REQUIRED
======================

You need to create 6 PNG texture files in this directory.

IMPORTANT: All textures must be exactly 512x512 pixels.

1. custom_wood_top.png      - Top face texture (512x512)
2. custom_wood_bottom.png   - Bottom face texture (512x512)
3. custom_wood_north.png    - North face (front) texture (512x512)
4. custom_wood_south.png    - South face (back) texture (512x512)
5. custom_wood_east.png     - East face (right side) texture (512x512)
6. custom_wood_west.png     - West face (left side) texture (512x512)

See TEXTURE_CREATION_GUIDE.md in the root folder for detailed instructions
on how to create these textures from real photos using free tools.

Each texture must be:
- PNG format
- Exactly 512x512 pixels (all 6 files must be the same size)
- Named exactly as shown above (case-sensitive)

Once you create these 6 files and place them in this directory, your resource pack
will be ready to use!
